数学可视化实验室 V2.2

本次重点修复：

1. 立方体展开图实验室
- 不再让每个面独立插值“飞向”目标位置。
- 六个面按原展开图的邻接关系建立父子铰链。
- 相邻面共享边在整个折叠过程中始终重合。
- 子面绕共享边旋转 90°；连接在子面上的后续面会一起被带动。
- 因此动画能直观看到平面展开图如何连续折成立方体。
- 保留六面文字和颜色自定义、播放/暂停/进度拖动。

2. 旋转体生成器
- 修正 Three.js LatheGeometry 与二维生成面的角度基准差异。
- 橙色二维生成面现在与蓝色扫掠体当前边界严格共面、贴合。
- 新增当前扫掠边界加深线，便于观察贴合关系。
- 保留 0°~360°动态播放、暂停、速度和角度控制。

其余实验沿用 V2.1。


V2.3 新增：
8. 圆锥曲线探索器
- 椭圆：焦点、准线、离心率、PF1+PF2=2a
- 双曲线：焦点、渐近线、准线、|PF1-PF2|=2a
- 抛物线：焦点、准线、PF=点到准线距离
- 可拖动轨迹点，实时显示标准方程和距离关系

9. 空间向量实验室
- a、b 两个三维向量分量可直接输入
- 实时计算长度、夹角、点积、叉积、正交投影
- 3D 可旋转视角
- 投影模式显示垂足关系
- 叉积模式显示向量张成的平面与法向量


V2.4 修复：
1. 圆锥曲线探索器
- Canvas 改为绝对定位铺满固定绘图区。
- ResizeObserver 只更新 Canvas 内部像素分辨率，不再写回 CSS width/height。
- 使用 requestAnimationFrame 合并 resize 回调，避免布局反馈循环和页面自动下移。

2. 空间向量实验室
- 重新设计向量输入区和统计区。
- a、b、投影、叉积采用更明确的颜色体系。
- 3D 标签不再直接压在箭头尖端，而是侧向偏移，并用细连接线指回向量端点。
- 标签采用白底彩色边框，提高复杂视角下的可读性。
- 新增立体 / 正视 / 侧视 / 俯视快捷视角。
- 降低坐标网格与坐标轴视觉强度，减少与向量主体竞争。


V2.4.1 空间向量字体兼容修复：
- 移除 Unicode 组合字符“字母 + 向量箭头(U+20D7)”。
- HTML 区域改用“向量 a / 向量 b / a · b / a × b”。
- 3D Canvas 标签只使用跨平台稳定字符：a、b、proj、a x b。
- 避免 Windows Chromium / Canvas 字体回退时出现小方框乱码。
